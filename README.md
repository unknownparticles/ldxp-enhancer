# 链动小铺增强工具（精简稳定版）

> 过滤缺货 + 价格排序 + 布局切换 + 控制面板（带按钮反馈）

## 功能
- ✅ 自动隐藏缺货商品
- ✅ 价格升序 / 降序排序
- ✅ Grid / List 布局切换
- ✅ 可拖拽控制面板 + 折叠
- ✅ 实时商品统计

## 安装
1. 打开 [Tampermonkey](https://www.tampermonkey.net/)
2. 安装油猴脚本
3. 安装链接：  
   `https://raw.githubusercontent.com/unknownparticles/ldxp-enhancer/main/dist/main.user.js`

## 快捷键
- 按 `Ctrl + Shift + E`（自定义，可在代码中修改）
